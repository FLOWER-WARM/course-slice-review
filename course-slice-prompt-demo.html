        素材与导入规则

        素材规则
        • 图片：直接粘贴截图（Ctrl+V）或用「插入图片」选文件；粘贴后自动补出【图片标题】【图片描述】两行，请补全文字。若来源软件只给了本地路径（浏览器读不到），会显示黄色提示，改用按钮插入即可。
        • 表格：从 Excel / 网页复制后粘贴，自动清理格式；粘贴后自动补出【表格标题】【表格描述】两行。
        • 代码：粘贴纯代码会自动识别语言（java / python / c / cpp / csharp / javascript / sql / r / matlab / html / shell / 伪代码），插入为带 ``` 语言标注 的代码块；也可用工具条的「粘贴剪贴板代码」「插入代码块」手动指定语言。导出 Word 时，代码正文每一行按模版要求设为 SourceCode 段落样式（Cambria 11pt），```语言 围栏行保持正文样式，缩进原样保留。
        • 公式：统一用 LaTeX 书写，两种排版——行内公式用 $…$ 包裹（嵌在文字中间），独立公式用 $$…$$ 包裹（单独成行）。可直接粘贴识别的来源：Word/WPS 复制的公式（OMML、MathML 家族）会自动转成 LaTeX（整段只有公式 → $$…$$，与文字混排 → $…$）；LaTeX / AsciiMath / Typst 公式文本（如 \frac{a}{b}）也自动识别。工具条的「插入行内公式 $…$」「插入独立公式 $$…$$」两个按钮会自动补出定界符并把光标停在中间。MathType 对象与截图位图公式无法提取，请手工重建。
        • 格式字段：按「内容」模块的实际内容自动显示（基础为文本，含图则为 文本/图片，依次可叠加 表格/公式/代码）；删除对应内容后相应标记会自动移除，也可手动修改。
        导入说明
        • 文档里以 #切片标题 开头的行表示一个新切片（如 #一、多向性），其后到下一个 # 之间的全部内容，自动填入该切片的「内容」模块。
        • 标题与骨架的切片标题自动匹配（忽略空格、全半角、反斜杠转义与序号符号差异，也可按「知识点」末级名称匹配）；「格式」字段按导入内容的实际类型自动显示（文本/图片/表格/公式/代码）。
        • 豆包等 AI 导出的 Markdown 兼容：自动还原 \. \( 等反斜杠转义与 **加粗** 等修饰标记；切片标题写在 ## / ### 层级（或 Word 里 # 被标题样式吞掉）时，带编号的标题同样识别；末尾「注：…AI 生成」声明、分隔线自动过滤；行内 $...$ 公式按原样式保留（行内 $…$、独立 $$…$$）。
        • 若上传的是本工具导出的切片 docx（含「格式 / 分类 / 知识点 / 来源 / 内容」标题 2 结构），只取「内容」部分，其余字段不覆盖。
        • 公式：Word 原生公式（OMML）与 MathML（无前缀 / mml: / m:）自动提取为 LaTeX 写入内容——整段只有公式时写独立公式 $$…$$，与文字混排时写行内公式 $…$；单独成行的 LaTeX / AsciiMath / Typst 公式文本同样识别（独立公式用 $$…$$）；MathType / 粘成图片的公式无法提取，需在 Word 中手工重建。识别到的公式会在导入结果报告里逐条列出，便于核对。

        导出

        • Word（.docx）：按《知识片段模版》的六字段结构输出，保留图片、表格和代码。公式以 LaTeX 文本保留。
        • Markdown（.md）：每个切片输出 # 完整切片标题 + 内容正文，末尾空行分隔；图片以 data URI 内嵌（文件会较大），公式按 LaTeX 原样保留（行内 $…$、独立 $$…$$），表格转成 Markdown 表格，代码保留语言围栏。该格式可被本工具的「批量导入内容」再次读取（勾选项开启「含字段」后会多出四行字段信息）。
        • 导出文件名取自右侧页面「导出文件名」输入框，留空则为「切片」；全部切片导出为一个文件，Word 版每片之间分页。
