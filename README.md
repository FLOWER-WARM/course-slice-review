# 知识切片制作与审核工具

将知识图谱、教材、教师课件和已有草稿整理成可编辑的知识切片，并导出为 Word 或 Markdown。前端负责教材解析、图片匹配、编辑和导出，Node.js 后端提供页面并转发默认 DeepSeek 接口的生成请求。

本地模型的训练、验证与接口接入见 [本地切片模型微调](docs/local-model-training.md)。教材、训练样本和权重仅保存在本地。

本机 OpenAI 兼容模型可使用 `localhost`、`127.0.0.1` 或 `::1` 的 HTTP 接口；无密钥的本机服务可留空 API Key。

## 如何运行

使用 Node.js 22 或更新版本，在项目目录中执行：

```powershell
npm ci
node server.mjs
```

打开 `http://127.0.0.1:3000`，点击「使用 API 自动生成」。使用者在网页填写完整接口地址、模型 ID 和 API Key，切换模型时可以直接修改。默认 DeepSeek 接口由本机后端转发，自定义 OpenAI 兼容接口由浏览器直连，需要服务商允许跨域。API Key 仅用于生成请求，应用没有持久化该字段。

也可以直接在 Edge 或 Chrome 中打开 `course-slice-review.html`。直接打开时，AI 生成沿用页面内配置接口的方式。旧版网页的浏览器缓存和本机服务页面各自保存状态，已有切片可先从旧页面导出，再导入新页面。部分文件格式解析和 Word 导出需要联网加载页面依赖。

## 使用流程

1. 导入 Excel 或 CSV 知识图谱，选择要整理的知识点。
2. 导入 Word 或 Markdown 草稿，或在生成面板中添加教材或 PPTX 课件并按知识点生成切片。
3. 在【内容】中核对正文、图片、表格和公式，再导出 Word 或 Markdown。

## 实现要点

- 教材插图按图号关联到正文。工具尝试从 DOCX 和文字版 PDF 提取并匹配插图，遇到歧义时可在页面选择候选，复杂 PDF 可手动框选。
- API 生成根据切片标题和图谱路径筛选教材段落，界面显示实际发送的原文字符数以及接口返回的 token 用量。
- Word 导出按切片模板组织字段，并保留正文中的图片和表格。通过本机服务导出时，LaTeX 会转成 Word 原生可编辑公式（OMML）。Markdown 导出继续保留 LaTeX。

## 使用教师课件生成

完整 HTML 和本机服务页面均可添加 PPTX，读取演示顺序中的文字、可编辑表格及教师备注，并保留页码。相同编号的小节可按图谱标题中的编号对应；“综合实操”等重名节点按完整路径中的模块与课件文件名区分。无对应编号时使用原有文本检索，仍需核对实际选中的材料。资料多义时不能把候选当成已确认匹配。

图片中的文字、截图表格、图表数据和公式没有自动视觉识别；纯图片页会提示补充，教师备注不代表原图已经核验。旧 `.ppt` 请先另存为 `.pptx`。课件不等同完整教材，生成后应核对知识框架、否定条件和模拟案例，实操节点不得虚构执行结果。

回归检查（需要本机 Edge，可联网加载页面依赖）：

```powershell
node scripts/test-pptx-source.mjs
# 若已启动本机服务，也可检查服务入口
node scripts/test-pptx-source.mjs http://127.0.0.1:3000
```

检查使用代码生成的微型课件，不包含教师材料、个人图谱或生成切片。
